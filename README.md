# 90-Day Discipline Tracker

A mobile-first, dark-theme installable web app for your 90-day plan. It uses plain HTML, CSS and JavaScript and stores progress in your browser's local storage. No account or backend is needed.

## Features
- Daily checklist for forex fundamentals, technical analysis, English, reading, mindset, programming, AI, business, gym/recovery, prayer and screen-time boundaries.
- Editable start date and 90-day phase overview.
- Daily schedule designed around Kenya time, with a note to move study blocks on workdays.
- Social media time limit and daily usage log.
- Focus/break timer.
- Weekly reflection notes.
- JSON export/import backup and full reset.
- Offline caching after first successful load.

## Run locally
For a quick preview, open `index.html` in a browser. Some install/offline features require serving the folder over HTTPS or localhost.

## Install on Android
1. Upload these files to a static HTTPS host (GitHub Pages is one option).
2. Open the published site in Chrome on Android.
3. Use the browser menu and select **Install app** or **Add to Home screen**. The install prompt appears automatically where supported.
4. Open the app from your home screen.

## Publish using GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Choose deployment from the `main` branch and `/ (root)`, then save.
5. After GitHub Pages publishes it, open the HTTPS URL on your phone.

## Data and privacy
All routine, checklist and review data is stored in the current browser on this device. It is not synced to other devices. Use **Export backup** before clearing browser data or changing phones. Import a backup to restore your progress. The app does not send your data to a server.

## Important note
The schedule is a template, not a requirement to work without breaks. Protect sleep and adjust around work and family commitments. Forex trading involves risk; practise and backtest before risking money.
